### Стандартные директории
| Название    | Описание                      |
| ----------- | ----------------------------- |
| layouts     | базовые слои                  |
| ↳ app       | конденсатор утилит и базы     |
| ↳ container | контейнер для любого контента |
| pages       | статичные страницы            |
| ↳ index     | главная                       |
| ↳ about     | описание                      |
| ↳ contacts  | контакты                      |
| ↳ policy    | политика сайта                |
| ↳ error     | страница ошибки               |
| partials    | мелкие куски страницы         |
| ↳ header    | хедер                         |
| ↳ alert     | уведомления                   |
| ↳ footer    | футер                         |
| components  | компоненты                    |
| auth        | страницы авторизации          |
| ↳ register  | регистрация                   |
| ↳ login     | вход                          |
| ↳ logout    | выход                         |
| ↳ reset     | сброс пароля                  |
| entities    | динамические сущности         |
| ↳ user      | пользователь                  |
