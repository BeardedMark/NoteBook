# Список полей для любых элементов

Часто у элементов есть типовой набор полей которые почти всегда задействуются при работе с элементами


| Псевдоним   | Название       | Тип      | Комментарий   |
| ----------- | -------------- | -------- | ------------- |
| code        | Уникальный код | string   | guid          |
| name        | Наименование   | string   |               |
| description | Описание       | text     |               |
| commentary  | Комментарий    | string   |               |
| tags        | Теги           | json     |               |
| isMain      | Основной       | boolean  |               |
| isPublic    | Публичный      | boolean  |               |
| slug        |                | string   |               |
| content     |                | longtext | html/markdown |
