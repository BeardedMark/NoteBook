Ниже — готовый комплект: **универсальный шаблон**, **вопросник для менеджера** и **словарь фраз**. Подходит для дистрибьютора (товары + опт + сервис).

---

# 1. Универсальный шаблон отзыва (готов к отправке клиенту)

```text
Кто вы:
(компания / ниша / формат — розница, маркетплейс, опт)

Задача:
(что нужно было — закупка, подбор ассортимента, поставки)

Что было до:
(проблемы / ограничения)

Что использовали:
(товар / услугу / формат работы с компанией)

Как проходил процесс:
(доставка, коммуникация, сроки, поддержка)

Результат:
(что изменилось — продажи, скорость, удобство)

Факты:
(цифры, сроки, объемы, %)

Где применяли:
(маркетплейсы, магазин, перепродажа и т.д.)

Итог:
(короткая рекомендация)
```

---

# 2. Готовый “собранный” пример (для ориентира клиенту)

> Мы интернет-магазин электроники, закупаем товары для перепродажи.  
> Искали поставщика с стабильными оптовыми поставками.  
> Раньше были перебои с наличием и долгой доставкой.  
> Начали работать с этим дистрибьютором, закупаем аксессуары оптом.  
> Поставки приходят вовремя, менеджер быстро отвечает.  
> За 2 месяца увеличили оборот на 30%, снизили количество возвратов.  
> Используем для продаж на маркетплейсах и в рознице.  
> Надежный поставщик для оптовых закупок и стабильной работы.

# 3. Вопросник для менеджера (чтобы “вытащить” отзыв)

Используй как скрипт:

### Блок 1 — контекст

- Кто вы и чем занимаетесь?
    
- Где продаете (маркетплейсы / розница / опт)?
    

### Блок 2 — задача

- Зачем обращались / закупали?
    
- Что для вас было важно?
    

### Блок 3 — проблема

- С какими трудностями сталкивались раньше?
    
- Почему искали нового поставщика?
    

### Блок 4 — опыт

- Что именно у нас использовали (товары / услуги)?
    
- Как прошел процесс (доставка, общение)?
    

### Блок 5 — результат (самый важный)

- Что изменилось после работы с нами?
    
- Есть ли цифры? (продажи, сроки, %)
    

### Блок 6 — применение

- Где используете товар? (перепродажа, магазин и т.д.)
    

### Блок 7 — финал

- Кому бы вы порекомендовали?
    
- За что цените больше всего?

# 4. Короткий шаблон (если клиент ленится)

```text
Мы [кто], закупали [что] для [задача].
Раньше было [проблема].
Сейчас используем [товар/услугу].
В итоге получили [результат + цифры].
Используем для [где].
Рекомендуем как [ключевая фраза].
```

# 5. Рекомендуемые слова и фразы (SEO-ядро)

### Для дистрибьютора:

- поставщик
    
- дистрибьютор
    
- оптовые поставки
    
- закупка товаров
    
- ассортимент
    

### Для B2B:

- для перепродажи
    
- для магазина
    
- для бизнеса
    
- оптовая цена
    
- закупаем оптом
    

### Для результата:

- увеличили продажи
    
- ускорили процесс
    
- снизили затраты
    
- сократили сроки
    
- вырос оборот
    

### Для доверия:

- стабильно
    
- надежно
    
- без перебоев
    
- в срок
    
- качественный товар
    

### Для сервиса:

- быстрая доставка
    
- удобная работа
    
- оперативная поддержка
    
- помогли с подбором

# 6. Как менеджеру собирать сильные отзывы

Алгоритм:

1. Задал вопросы (выше)
    
2. Получил “сырой” ответ
    
3. Привел к структуре (шаблон)
    
4. Добавил:
    
    - конкретику
        
    - 1–2 ключевые фразы
        
    - нормальный финал
        

---

# 7. Усиление (чтобы было мощнее конкурентов)

Можно добавить:

- тег (опт / маркетплейсы / розница)
    
- нишу клиента (электроника, одежда и т.д.)
    
- цифры (даже примерные)
    
- формат: “кейс клиента”
    

---

# 8. Типичные ошибки

❌ нет контекста (“всё понравилось”)  
❌ нет результата  
❌ нет ключевых слов

✔ есть сценарий + результат + ключ
