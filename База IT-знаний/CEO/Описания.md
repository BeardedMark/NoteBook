Ниже — такая же “шпаргалка”, но для **описаний товаров, категорий и производителей**. Сразу ориентировано под дистрибьюцию (опт + B2B + маркетплейсы).

---

# 1. Шаблон описания товара

```text
Название товара:
(модель + тип + ключевая фраза)

Краткое описание (1–2 строки):
что это + для кого + ключ

Для кого:
(розница / бизнес / перепродажа)

Назначение:
где и как используется

Ключевые характеристики:
(список — конкретика)

Преимущества:
(почему лучше — 3–5 пунктов)

Применение:
(сценарии использования)

Результат:
что получает клиент

Для опта:
(если актуально — маржа / спрос / стабильность)

Итог:
короткое резюме с ключевой фразой
```

---

## Пример

> Зарядное устройство USB-C 20W для смартфонов  
> Компактное решение для быстрой зарядки мобильных устройств. Подходит для розницы и перепродажи.  
> Используется для зарядки смартфонов, планшетов и аксессуаров.  
> Поддерживает быструю зарядку, стабильную работу и защиту от перегрева.  
> Отличается высоким спросом и низким процентом возвратов.  
> Подходит для продажи в магазинах электроники и на маркетплейсах.  
> Надежный товар для оптовых закупок и стабильной реализации.

---

# 2. Шаблон описания категории (каталога)

```text
Название категории:
(с ключом)

Вводный блок:
что это за категория + кому подходит

Ассортимент:
какие товары входят

Для кого:
(бизнес / розница / маркетплейсы)

Преимущества категории:
(выгоды)

Применение:
где используется

Почему выгодно закупать:
(опт, спрос, оборачиваемость)

Как выбрать:
(критерии выбора)

Итог:
закрывающий абзац с ключами
```

---

## Пример

> Аксессуары для смартфонов оптом  
> Категория включает зарядные устройства, кабели, наушники и другие товары для мобильных устройств.  
> Подходит для магазинов электроники, маркетплейсов и перепродажи.  
> Товары отличаются стабильным спросом и высокой оборачиваемостью.  
> Отличный выбор для формирования ассортимента и увеличения продаж.

---

# 3. Шаблон описания производителя / бренда

```text
Название бренда:

Кто это:
(производитель / страна / позиционирование)

Специализация:
(какие товары производит)

Преимущества:
(качество, технологии, цена)

Ассортимент:
(основные категории)

Почему выбирают:
(доверие, стабильность)

Для бизнеса:
(почему выгодно продавать)

Итог:
позиционирование бренда
```

---

## Пример

> Производитель аксессуаров для мобильных устройств из Китая.  
> Специализируется на зарядных устройствах и кабелях.  
> Известен стабильным качеством и доступной ценой.  
> Продукция подходит для оптовых закупок и перепродажи.  
> Популярный бренд для маркетплейсов и розничных магазинов.

# 4. Вопросник для менеджера (сбор данных)

## Для товара:

- Что это за товар?
    
- Для кого он (B2B / розница)?
    
- Где используется?
    
- В чем его ключевая выгода?
    
- Чем лучше аналогов?
    
- Есть ли цифры (спрос, возвраты)?
    
- Где продается (маркетплейсы / магазины)?
    

---

## Для категории:

- Какие товары входят?
    
- Для какой аудитории?
    
- Какие самые популярные позиции?
    
- Почему категория продается?
    
- Какие задачи закрывает?
    

---

## Для производителя:

- Кто это (страна, позиционирование)?
    
- Что производит?
    
- Чем отличается?
    
- Почему его покупают?
    
- Подходит ли для опта?

# 6. Быстрые формулы (для ускорения)

### Товар:

```text
[что это] + для [кого] + решает [задачу] + дает [результат]
```

### Категория:

```text
[категория] включает [товары] + подходит для [ЦА] + дает [выгоду]
```

### Производитель:

```text
[бренд] — это [кто] + специализируется на [чем] + отличается [чем]
```

---

# 7. Как усилить (под твой уровень)

Ты можешь сделать систему:

- шаблон → форма → генерация описания
    
- авто-вставка ключей
    
- вариативные тексты (под SEO / маркетплейс / лендинг)
    
- связка:
    
    - товар → категория → бренд → отзывы
        

👉 это уже полноценный контент-движок

---

# 8. Ошибки

❌ просто характеристики  
❌ нет “для кого”  
❌ нет сценария использования

✔ есть: применение + выгода + контекст
