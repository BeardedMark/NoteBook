# Шпаргалка по микроразметке для сниппетов сайта

## Что такое микроразметка

Микроразметка — это структурированные данные, которые помогают поисковикам понимать содержимое страницы.

Используется для:
- красивых сниппетов в Google/Яндекс
- карточек товаров
- FAQ
- хлебных крошек
- рейтингов
- организации
- статей
- рецептов
- событий
- видео
- вакансий и т.д.

Основной стандарт:
- Schema.org → [Schema.org](https://schema.org/?utm_source=chatgpt.com)

Проверка:
- Google Rich Results → [Google Rich Results Test](https://search.google.com/test/rich-results?utm_source=chatgpt.com)
- Schema Validator → [Schema Markup Validator](https://validator.schema.org/?utm_source=chatgpt.com)

---

# Какой формат использовать

## Лучший вариант — JSON-LD

Google рекомендует именно его.

Вставляется в `<script>`.

Пример:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "My Company",
  "url": "https://example.com"
}
</script>
```

---

# Базовые правила

## 1. Используй только реальные данные

Нельзя:
- подделывать рейтинг
- писать фейковые отзывы
- скрывать данные

---

## 2. Разметка должна соответствовать контенту страницы

Если на странице нет FAQ — нельзя размечать FAQ.

---

## 3. Не дублируй одинаковые сущности

Лучше:
- один `Organization`
- один `Product`
- один `Article`

---

## 4. Всегда указывай `@context`

```json
"@context": "https://schema.org"
```

---

# Базовый шаблон страницы

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebPage",
  "name": "Название страницы",
  "url": "https://example.com/page"
}
</script>
```

# Самые важные типы микроразметки

---

# 1. Organization / LocalBusiness

Для компании.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "DNL Market",
  "url": "https://example.com",
  "logo": "https://example.com/logo.png",
  "email": "info@example.com",
  "telephone": "+79999999999",
  "sameAs": [
    "https://vk.com/company",
    "https://t.me/company"
  ]
}
</script>
```

---

## LocalBusiness

Если есть физический адрес.

```json
{
  "@type": "LocalBusiness",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Улица",
    "addressLocality": "Новосибирск",
    "addressCountry": "RU"
  }
}
```

---

# 2. BreadcrumbList

Хлебные крошки.

Очень полезно для SEO.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Главная",
      "item": "https://example.com"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "Каталог",
      "item": "https://example.com/catalog"
    }
  ]
}
</script>
```

---

# 3. Article / BlogPosting

Для статей и блога.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BlogPosting",
  "headline": "Как настроить Laravel",
  "description": "Полный гайд",
  "image": "https://example.com/image.jpg",
  "author": {
    "@type": "Person",
    "name": "Иван"
  },
  "publisher": {
    "@type": "Organization",
    "name": "DNL"
  },
  "datePublished": "2026-05-12",
  "dateModified": "2026-05-12"
}
</script>
```

---

# 4. Product

Для товаров.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "iPhone 17",
  "image": [
    "https://example.com/img.jpg"
  ],
  "description": "Описание",
  "sku": "IPHONE17",
  "brand": {
    "@type": "Brand",
    "name": "Apple"
  },
  "offers": {
    "@type": "Offer",
    "url": "https://example.com/product",
    "priceCurrency": "RUB",
    "price": "99990",
    "availability": "https://schema.org/InStock"
  }
}
</script>
```

---

# 5. AggregateRating

Рейтинг товара.

```json
{
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.8",
    "reviewCount": "124"
  }
}
```

Обычно вкладывается внутрь `Product`.

---

# 6. FAQPage

FAQ-блок.

Очень мощный тип для SEO.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Как оплатить?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Оплата картой"
      }
    }
  ]
}
</script>
```

---

# 7. WebSite + SearchAction

Поиск по сайту.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "url": "https://example.com",
  "potentialAction": {
    "@type": "SearchAction",
    "target": "https://example.com/search?q={query}",
    "query-input": "required name=query"
  }
}
</script>
```

---

# 8. Person

Для автора, эксперта, профиля.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "Иван Иванов",
  "url": "https://example.com/about",
  "jobTitle": "Laravel Developer"
}
</script>
```

---

# 9. VideoObject

Для видео.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "VideoObject",
  "name": "Laravel Guide",
  "thumbnailUrl": "https://example.com/thumb.jpg",
  "uploadDate": "2026-05-12",
  "contentUrl": "https://example.com/video.mp4"
}
</script>
```

---

# 10. Event

Для мероприятий.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Event",
  "name": "Laravel Meetup",
  "startDate": "2026-06-01T19:00",
  "location": {
    "@type": "Place",
    "name": "Conference Hall"
  }
}
</script>
```

---

# Вложенность объектов

Schema.org работает как дерево.

Пример:

```json
{
  "@type": "Product",
  "offers": {
    "@type": "Offer"
  },
  "brand": {
    "@type": "Brand"
  }
}
```

# Как внедрять в Laravel

## Blade-компонент

```php
<script type="application/ld+json">
{!! json_encode($schema, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES) !!}
</script>
```

---

## Пример генерации

```php
$schema = [
    '@context' => 'https://schema.org',
    '@type' => 'Product',
    'name' => $product->name,
];
```

---

# Полезная архитектура для Laravel

Ты как Laravel-разработчик можешь сделать:

```php
Schema::product($product)
Schema::article($article)
Schema::organization()
Schema::breadcrumbs($items)
```

И возвращать массивы.

Потом:
- объединять
- кешировать
- автоматически вставлять в layout

Это очень чистая архитектура.

---

# Что реально влияет на SEO

Наиболее полезные:

- Product
- FAQ
- Breadcrumb
- Article
- Organization
- LocalBusiness

---

# Что НЕ гарантирует микроразметка

Микроразметка:

- НЕ гарантирует rich snippets
- НЕ гарантирует рост SEO
- НЕ гарантирует позиции

Но:

- повышает CTR
- помогает индексации
- улучшает понимание структуры сайта

# Частые ошибки

## Неправильно

```json
"price": 1000
```

Лучше:

```json
"price": "1000"
```

---

## Неправильный URL

```json
"url": "/product"
```

Лучше полный URL:

```json
"url": "https://example.com/product"
```

---

## Неправильная дата

```json
"datePublished": "12.05.2026"
```

Правильно:

```json
"datePublished": "2026-05-12"
```

---

# Полезные enum значения

## Наличие товара

```json
"https://schema.org/InStock"
"https://schema.org/OutOfStock"
"https://schema.org/PreOrder"
```

# Когда вставлять микроразметку

Лучше:

- в `<head>`
- либо перед `</body>`

JSON-LD не зависит от DOM.

# Идеальная архитектура для твоих проектов

Для Laravel/Vue стартапов тебе выгодно сделать:

- единый Schema Builder
- DTO для схем
- авто-генерацию из моделей
- кеширование JSON-LD
- SSR-рендер схем
- динамические breadcrumbs
- schema policy system

Пример:

```php
ProductSchema::make($product)->toScript()
```

или:

```php
@schema($product)
```

Это уже уровень полноценного SEO-engine внутри проекта.
