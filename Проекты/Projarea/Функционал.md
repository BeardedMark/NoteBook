## 1. Карточка проекта (ядро продукта)

**Контент:**
- Название
- Слоган
- Подробное описание (Markdown + блоки)
- Категории / теги
- Статус проекта:  
    `идея / в разработке / MVP / бета / релиз / заморожен`
- Цели проекта:  
    `фидбек / команда / пользователи / инвестиции / портфолио`
- Стек технологий
- Скриншоты / видео / GIF
- Внешние ссылки: сайт, демо, GitHub, Figma, Discord, Telegram
- Дата старта
- Последнее обновление
- Лицензия / open-source или нет
- Язык проекта

**Метаданные:**
- Просмотры
- Подписчики
- Активность
- Индикатор «живости»

---

## 2. Участники проекта

- Добавление участников
- Роли:  
    `основатель / dev / дизайнер / PM / маркетинг / тестер`
- Уровень участия: core / contributor / advisor
- Навыки участника в проекте
- Дата вступления
- Статус: активен / вышел
- Контакты участника (опционально)

---

## 3. Поиск команды и вакансии

**Внутри проекта:**
- Открытые роли:
    - название роли
    - требования
    - задачи
    - формат: бесплатно / % / оплата
    - занятость: part-time / full-time
    - удалёнка / нет

**Для пользователей:**
- Отклик на роль
- Сообщение основателю
- Статусы отклика
- История откликов

---

## 4. Профиль пользователя
- Имя / ник
- Аватар
- Роль (dev, designer и т.д.)
- Навыки + уровни
- Стек
- Опыт
- Биография
- Ссылки: GitHub, LinkedIn, Habr, Telegram
- Проекты пользователя
- Статус:  
    `ищу проект / открыт к предложениям / не ищу`

## 17. MVP-ядро (чтобы не утонуть)

Минимум, с которого тебе логично стартовать:
- Регистрация / логин
- Профиль пользователя
- Создание карточки проекта
- Категории + теги
- Участники проекта
- Открытые роли
- Отклики
- Комментарии
- Каталог + поиск
- Подписка на проект
