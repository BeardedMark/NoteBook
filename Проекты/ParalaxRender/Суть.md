## Данные
1. JSON объект карты
	1. Основная информация о карте
	2. Список расположения объектов
2.  JSON список предметов
## Алгоритмы
- Фрустум - определяет область в которой координаты будут обработаны
- Коллизия - обработка столкновений областей объектов на карте
## Действия
- Передвижение - WASD
- Прыжок/исчезновение - Space
- Ускорение - Shift
- Замедление/присест - Ctrl
