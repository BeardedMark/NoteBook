# Как формировать сцены карты
## Термины
- Frustum (фрустум) - область координат для рендера сцен
- Paralax (паралакс) - смещение слоев относительно друг друга для эффекта объема
- Depth (глубина) - изменение размеров, прозрачности и размытия при отдалении
- Camera (камера) - координаты местоположения на карте
- Render (рендер) - отрисовка сцены по координатам
	- 2D - стандартное построение координатной плоскости
	- 3D - алгоритм построения координат фрустума

# Основной алгоритм
1. Загрузить **json** файл карты
2. Определить координаты **камеры**
3. Определить **frustum** область
4. Рендер сцен
	1. 2D сцена
		1. наложение эффектов на сцену (фильтр)
		2. canvas с отладочными элементами (инструмент)
		3. svg объектами на сцене (интерактив)
		4. canvas отрисовка земли (оформление)
	2. 3D сцена
		1. наложение эффектов на сцену (фильтр)
		2. canvas с отладочными элементами (инструмент)
		3. svg объектами на сцене (интерактив)
		4. canvas отрисовка земли и неба (оформление)

Отладочный слой (показывает техническую информацию)
 1. Сетка плоскости
 2. Область фрустума
 3. Область действий
 4. Области коллизий
 5. Курсор треккер
