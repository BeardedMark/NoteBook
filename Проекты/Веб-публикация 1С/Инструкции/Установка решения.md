
1. Подготовить 1С
	1. Добавить файл расширения в 1С
	2. Настроить веб-публикацию в 1С
	3. Создать запись настроек в 1С
	4. Сделать маршрутизацию через домен с сертификатом
2. Подготовить Сайт
	1. Создать хостинг ([Timeweb](https://hosting.timeweb.ru/sites))
	2. Создать и привязать [домен](https://hosting.timeweb.ru/domains) на хостинге
	3. Подключить [SSL сертификат](https://hosting.timeweb.ru/ssl#order) на домен
	4. Выложить файлы сайта на хостинг
	5. Настроить сайт для подключения к 1С
