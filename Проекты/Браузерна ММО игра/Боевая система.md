# Универсальная основа боев
Вдохновлено базовой механикой Камень-Ножницы-Бумага

| Камень | Ножницы | Бумага      |
| ------ | ------- | ----------- |
| защита | атака   | действие    |
| броня  | оружие  | расходники  |
| тело   | руки    | способности |

## Основа
- АЗД система (атака, защита, действие, бездействие)
- ППН статистика (победы, поражения, ничьи)
- Бои - список 
	- Вступление в бой (подготовка)
		- на странице боев выбирается или создается бой
		- после вступления в одну из команд идет ожидание начала
		- после вступления нельзя менять экипировку
		- можно сменить команду или выйти из ожидания боя
	- Процесс боя
		- начинается бой и идет время подготовки
		- после подготовки каждому игроку подбирается оппонент
		- всем игрокам в бою дается время на шаг (выбор действия)
		- по окончанию времени высчитывается результат хода

## Геймплей
- Создается профиль и персонаж
- Участие в боях, получение опыта и ресурсов
- Прокачка показателей и смена экипировки

## Варианты исходов в бою

| вы\враг      | Атака                 | Защита                 | Действие         |
| ------------ | --------------------- | ---------------------- | ---------------- |
| **Атака**    | оба получили урон     | враг заблокировал урон | вы нанесли  урон |
| **Защита**   | вы заблокировали урон | оба бездейстуют        | враг действует   |
| **Действие** | вы получили урон      | вы действуете          | оба действуют    |
## Данные

- Персонаж
	- Опыт для вычисления уровня по формуле
	- Здоровье как ресурс для победы
	- СЛИ показатели (сила, ловкость интеллект)
	- ОБУ экипировка (оружие, броня, умения)
- Бой
	- название и описание
	- кол-во команд в бою (2-6)
	- кол-во участников в команде (1-24)
	- смена оппонента после хода (да/нет)
	- время шага (1-60 сек)
	- время подготовки (1-10 мин)
	- тип (тренировочный, обычный, жестокий, рейтинговый)
## Страницы

- Статичные (page)
	- Главная (main)
	- О проекте (about)
	- Контакты (contacts)
- Авторизация (auth)
	- Регистрация - создание нового профиля (register)
	- Вход - доступ к существующему профилю (login)
	- Восстановление доступа - восстановление доступа к профилю (recovery)
- Профиль (user)
	- Личный кабинет - приватная страница профиля (edit)
	- Профиль пользователя - публичная страница (show)
	- Список профилей - все пользователи на сайте (index)
- Персонаж (character)
	- Создание - новый персонаж (create)
	- Редактирование - приватная страница персонажа (edit)
	- Описание - публичное описание персонажа (show)
	- Список - свои и чужие персонажи (index)
	- Удаление - подтверждение удаления персонажа (remove)
- Бои (battle)
	- Список боев - посмотреть текущие, завершенные или открытые (index)
	- Создание боя - создание нового боя и указание настроек (create)
	- Страница боя - просмотр информации о бое и логов (show)
	- Страница ведения боя - страница процесса для участников боя (edit)
