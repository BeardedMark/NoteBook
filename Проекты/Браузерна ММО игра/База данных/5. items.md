# Предметы

| Название         | Тип    | Комментарий                | Значение         |
| ---------------- | ------ | -------------------------- | ---------------- |
| code             | string | код                        | uniq             |
| name             | string | имя                        | uniq             |
| description      | text   | описание                   | null             |
| image            | string | портрет                    | null             |
| sound            | string | звучание                   | null             |
|                  |        |                            |                  |
| weight           | float  | вес                        | 0                |
| drop_chance      | float  | шанс появления             | 0                |
| min_level        | int    | минимальный уровень        | null             |
| max_level        | int    | размер                     | null             |
| is_assemble      | bool   | собираемый                 | false            |
| is_disassemble   | bool   | разбираемый                | false            |
|                  |        |                            |                  |
| items_list       | json   | предметы в рецепте         | [[5. items]]     |
| ↳ item_code      | string | предмет                    |                  |
| ↳ count_items    | int    | количество предметов       |                  |
| ↳ drop_chance    | float  | шанс выпадения при разборе |                  |
| modifier_pool    | json   | возможные модификаторы     | [[0. modifiers]] |
| requirement_lsit | json   | требования                 |                  |
